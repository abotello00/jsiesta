# Pseudopotentials for the examples and tutorials

`H.psml`, `C.psml`, `O.psml` and `Si.psml` are unmodified files from the PseudoDojo project: optimised
norm-conserving Vanderbilt (ONCVPSP) pseudopotentials, scalar-relativistic, PBE, "standard" accuracy, table
`nc-sr-04_pbe_standard`, in PSML format (downloaded from http://www.pseudo-dojo.org).

- PseudoDojo is described in M. J. van Setten, M. Giantomassi, E. Bousquet, M. J. Verstraete, D. R. Hamann,
  X. Gonze and G.-M. Rignanese, *The PseudoDojo: Training and grading a 85 element optimized norm-conserving
  pseudopotential table*, Comput. Phys. Commun. **226**, 39 (2018). Please cite it when you use these files.
- The PSML format: A. García, M. J. Verstraete, Y. Pouillon and J. Junquera, *The PSML format and library for
  norm-conserving pseudopotential data curation and interoperability*, Comput. Phys. Commun. **227**, 51 (2018).
- The PseudoDojo pseudopotentials are distributed under the Creative Commons Attribution 4.0 licence (CC BY 4.0).

The full tables (all elements, other functionals, fully relativistic versions for spin-orbit calculations) are
available from the PseudoDojo web site; choose "psml" as the format.
