jsiesta Documentation
=====================

Clean-room **JAX + C++** implementation of static single-point **SIESTA**
Kohn-Sham DFT with PSML-only pseudopotentials, uniform 3D FFT real-space grid,
native ``spglib`` crystal/magnetic symmetry, and ``scf_params`` adaptive SCF.
